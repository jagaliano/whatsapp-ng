Preserve original copyright and Git history. Historical evidence must use descriptive legacy labels/README links, never misidentify old artifacts as new ones. - Default data root: `~/.pi/agent/extensions/whatsapp-ng`. Move all state together: configuration, default/group auth, persistent profile/account metadata, archives/recents, downloaded media and logs. Preserve relative auth profile names and archive UUID/account bindings. Never merge an existing destination or silently create fresh credentials.
- Explicit source path only: startup flag `--whatsapp-ng-migrate-from` or a private pending request prepared by the operator. No hardcoded legacy-name fallback. Normal startup must finish pending migration before any directory creation, settings persistence, archive writer or socket work; failures remain blocked rather than using defaults.
- Migrate by same-filesystem atomic directory rename, not credential copying. Require all owning processes/services stopped; reject runtime locks, symlinks, overlapping roots, unexpected/interrupted metadata and destination conflicts. Preserve private directory/file boundaries. Never delete or steal active/unknown/stale locks. Cross-filesystem migration stops rather than copying secrets.
- Persist a private non-secret sibling request/journal with source directory identity before moving. Interrupted moves may resume only when destination identity proves it is the same moved source; never infer from an unrelated destination. Keep recoverable state on failure. Root migration ownership remains outside the moved tree.
- Initialize configuration before any status write; do not reproduce controller settings loss. Constructors and file loggers, including shutdown logging, must not create or modify the new root before migration. Initiate migration only once per process/destination, retaining the outcome across session replacement and extension recreation. Failures and newly queued requests require a fresh process, never a hot-reload retry. Safely shut down old runtime callbacks before real migration.
